# 서브 서비스 유저 데이터 이관 매뉴얼 (User Migration Guide)

## 1. 개요 및 사용 상황
* **발생 배경**: 감쓰(`dumpit`) 및 어드벤트 캘린더(`advent`)의 카카오 로그인 앱을 하루상자 중앙 카카오 앱(`eab615e444cb...`)으로 통합함에 따라, 기존 카카오 앱 키로 가입했던 유저가 재로그인할 때 신규 계정(새 카카오 회원번호)이 생성됩니다.
* **사용 상황**: 지인이 다시 접속했을 때 *"이전에 만든 캘린더나 글, 메시지가 사라졌어요"*라고 문의하는 경우 사용합니다.
* **해결 원리**: 이전 계정에 묶여 있는 수파베이스(Supabase) 데이터 소유권(캘린더, 글, 댓글, 메시지 등)을 새로 로그인된 계정 ID로 1:1 이전하고 이전 더미 계정을 정리합니다.

---

## 2. 사전 조건
반드시 **해당 사용자가 통합된 서비스(어드벤트 또는 감쓰)에서 카카오 로그인을 최소 1회 진행한 직후**에 실행해야 합니다. (새 계정이 DB에 생성되어 있어야 매핑이 가능합니다.)

---

## 3. 실행 방법 (CLI 명령어)

하루상자 프로젝트 루트 디렉토리(`/Users/shkim/Desktop/Project/haroo-box`)에서 실행합니다:

```bash
node scripts/migrate-user.js <서비스명> <유저이름> [로그인수단]
```

### 파라미터 안내
* `<서비스명>`: `advent` (어드벤트 캘린더) 또는 `dumpit` (감쓰)
* `<유저이름>`: 카카오 프로필 닉네임 (예: `김이나`, `하나`, `수연`)
* `[로그인수단]`: 기본값 `kakao` (구글 계정인 경우 `google`)

### 실행 예시
```bash
# 예시 1: 어드벤트 캘린더 '김이나' 유저 데이터 이관
node scripts/migrate-user.js advent 김이나 kakao

# 예시 2: 감쓰 '하나' 유저 데이터 이관
node scripts/migrate-user.js dumpit 하나 kakao
```

## 4. 후속 조치 (Supabase SQL 실행)

스크립트를 실행하면 콘솔에 아래와 같이 **자동 생성된 SQL 쿼리**가 출력됩니다:

1. 콘솔에 출력된 `DO $$ ... END $$;` 블록을 전체 복사합니다.
2. 대상 서비스의 **Supabase 대시보드 ➔ SQL Editor**에 붙여넣고 **Run**을 실행합니다:
   * 어드벤트 캘린더: `lrpehigfvwddizepghnc` 프로젝트
   * 감쓰: `ldrkjdiscyhbiybwogpa` 프로젝트
3. SQL 실행이 완료되면 즉시 해당 지인의 이전 데이터가 새 계정으로 100% 복구됩니다.
4. (선택) 스크립트 하단에 안내되는 MongoDB 정리 한 줄 명령어를 터미널에 붙여넣어 이전 더미 레코드를 삭제합니다.
