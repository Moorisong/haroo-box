# 💌 하루엽서 프론트엔드 기획 명세서 (postcard-frontend.md)

본 문서는 하루상자 모노레포(`apps/web`) 환경 내에 통합 구현되는 모바일 퍼스트 웹 서비스인 '하루엽서'의 프론트엔드 UI/UX 사양 및 프레임워크 구현 가이드입니다.

---

## 🎯 1. 서비스 목적 및 방향성
- **일상의 온도 전달**: 소소한 일상 감성의 사진, 메시지, 폰트, BGM을 조합한 맞춤형 디지털 엽서 제작.
- **모바일 퍼스트**: 링크를 통해 모바일 기기에서 주로 열람하므로, 9:16 세로 화면 비율 및 터치 친화적 조작감 극대화.
- **3일의 희소성**: 3일(72시간) 동안만 열람 가능한 영속성 제한(TTL)을 시각적으로 강조하여 특별한 경험 제공.

---

## 📐 2. 공통 디자인 시스템 및 레이아웃
- **컬러 시스템 (`ui_design_spec.md` 계승)**:
  - **Primary**: `#6C5CE7` (Medium Slate Blue)
  - **Secondary**: `#A29BFE` (Light Slate Blue)
  - **Accent**: `#FD79A8` (Pink / Rose)
  - **배경색 무드**: 웜톤 `#F9F6F0` (클래식 빈티지) 및 다크모드 `#121212` (밤하늘 감성) 제공.
- **감성 타이포그래피 (5종 고딕 큐레이션)**:
  1. `font-1` (모던 고딕): Nanum Gothic 등 (깔끔하고 세련됨)
  2. `font-2` (고딕): Nanum Gothic 등
  3. `font-3` (레트로 고딕): Nanum Gothic 등 (빈티지하고 아기자기함)
  4. `font-4` (시네마틱 고딕): Noto Sans KR 등 (선명하고 또렷함)
  5. `font-5` (라운드 고딕): Nanum Gothic 등 (다정하고 친근함)
- **공통 네비게이션 헤더**:
  - `apps/web/components/layout/` 하위의 공통 네비게이션 헤더를 상단에 고정 연동.
  - 하루상자 로고, 메인 메뉴, 로그인 상태 및 경로 이동 인터랙션 지원.

## 📱 3. 화면별 UI/UX 명세

### [Page 1] 메인 / 랜딩 페이지 (`/`)
- **라우트**: `/` (기존 하루상자 메인에 엽서 서비스 소개 추가 또는 `/postcard` 진입로 연동)
- **화면 구성**:
  - **상단**: 하루상자 공통 헤더
  - **중앙**: 감성 캐치프레이즈 (*"당신의 하루에 어울리는 온도를 전해보세요"*) 및 엽서 예시 프리뷰 슬라이더 (3초 자동 전환 전용, 호버/클릭 인터랙션 비활성화).
  - **하단 인라인 CTA**: TTL 안내 문구 바로 아래 본문 영역 내 위치한 둥근 모양의 CTA 버튼 `[ 💌 나만의 하루엽서 만들기 ]` (`/create` 이동).

### [Page 2] 엽서 제작 페이지 (`/create`)
- **라우트**: `/create` (또는 `/postcard/create`)
- **UI 구조**: 싱글 페이지 폼 내 Stepper(단계별) UI
- **단계별 사양**:
  - **Step 1. 사진 업로드 & 필터**:
    - 이미지 드래그앤드롭/터치 업로드.
    - 필터 프리셋 3종: Vintage, Monotone, Film Grain 및 실시간 프리뷰.
    - 3D 입체 반사 빛 효과 토글 스위치.
  - **Step 2. 문구 입력 & 폰트 선택**:
    - 텍스트 입력 영역 (최대 150자 제한, 실시간 글자수 카운팅 및 유효성 검증).
    - 폰트 5종 선택 버튼 UI: 클릭 시 실시간으로 엽서 이미지 내 텍스트 폰트 변경.
  - **Step 3. BGM 등록**:
    - 유튜브 링크 입력창 (링크 형식 정규식 검증).
    - 올바른 링크 입력 시, YouTube Data API 또는 백엔드 파싱을 거쳐 썸네일과 비디오 제목 카드 실시간 렌더링.
  - **하단 고정 CTA**: `[ 🔗 3일짜리 감성 엽서 링크 만들기 ]` (Zustand 상태 취합 후 API 전송 및 `/ad-gate/:id`로 이동).

### [Page 3] 광고 브릿지 페이지 (`/ad-gate/:id`)
- **라우트**: `/ad-gate/:id` (또는 `/postcard/ad-gate/:id`)
- **UI 구성**: 엽서 생성 직후 거쳐가는 감성형 대기 화면.
- **주요 요소**:
  - 안내 메시지: *"잠시만요! 소중한 엽서를 꺼내어 담는 동안, 작은 여유의 광고를 만나보세요."*
  - 카카오 애드핏 배너 영역: 카드 디자인 내에 자연스럽게 임베드된 광고 유닛.
  - 3초 최소 대기 타이머 설정.
  - **하단 CTA**: `[ 💌 엽서 보러가기 (공유·저장 활성화) ]` (광고 노출 시간 경과 후 활성화, `/share/:id` 이동).

### [Page 4] 공유 완료 페이지 (`/share/:id`)
- **라우트**: `/share/:id` (또는 `/postcard/share/:id`)
- **UI 구성**: 생성된 엽서 카드 프리뷰 및 링크 관리.
- **주요 요소**:
  - 안내 메시지: *"링크가 생성되었습니다. (3일 뒤 사라집니다)"* 및 디데이 타이머.
  - **공유 액션 그룹**:
    - 카카오톡 공유하기 (`next/public` 카카오 SDK 로딩 및 템플릿 연동).
    - 엽서 주소 링크 복사 버튼 (클립보드 API 연동, 복사 성공 토스트 노출).
    - 이미지 다운로드 버튼 (`html-to-image` 또는 Canvas 렌더링 활용).

### [Page 5] 엽서 뷰어 페이지 (`/view/:id`)
- **라우트**: `/view/:id` (또는 `/postcard/view/:id`)
- **동적 분기 처리**:
  - **Case A: 72시간 이내 (정상)**:
    1. **1단계 (감성 모달)**: 화면 블러 상태에서 오디오 권한 승인 유도.
       - `[ 🎧 음악과 함께 엽서 열기 ]` -> 오디오 재생 활성화 + Three.js 엽서 페이드인
       - `[ 🤫 조용히 엽서만 볼래요 ]` -> 무음 처리 + Three.js 엽서 페이드인
    2. **2단계 (메인 뷰어)**: Three.js 기반 3D 입체 엽서 렌더링. 
       - 자이로스코프(모바일) 또는 마우스 드래그에 반응하는 3D 기울기 및 빛 반사 효과.
       - 하단에 미니멀 유튜브 오디오 재생 바 노출 (Play/Pause, 볼륨 조절).
       - 바이럴 배너: `[ 나도 하루엽서 만들러 가기 ]`.
  - **Case B: 3일 만료된 경우**:
    - 빈티지 티켓 모티브의 안내창: *"앗, 유효기간(3일)이 지나 추억 속으로 사라진 엽서입니다."*
    - 메인 이동 CTA: `[ 엽서 만들러 가기 ]`.
