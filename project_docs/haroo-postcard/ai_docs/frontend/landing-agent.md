# Haroo Postcard Landing Agent Reference

## 📝 1. 연동 기획 명세 (postcard-frontend.md)
- 하루상자 메인 앱에 진입한 유저에게 '하루엽서' 서비스를 소개하는 첫 관문 페이지.
- 세로형 원페이지 스크롤 형태를 지향하며, 서비스의 감성과 감동을 직관적으로 표현하는 예시 엽서 프리뷰 슬라이더 제공.
- 하단 고정 CTA 버튼을 통해 엽서 제작 기능(`/create`)으로 유도.

## 🤖 2. AI 개발 지침 및 설계 구조
### 🎯 목적
- 랜딩 페이지의 시각적 매력을 극대화하여 엽서 제작 단계로 매끄럽게 전환 유도.
- 모바일 화면 비율(9:16) 및 데스크톱 반응형에 맞춘 레이아웃 붕괴 방지 구현.

### 📦 패키지 및 타깃 클래스 경로 구조
- 메인 페이지 연동 경로: `apps/web/app/postcard/page.tsx` 또는 `apps/web/app/page.tsx` 내 섹션 컴포넌트화.
- 컴포넌트 경로: `apps/web/components/postcard/LandingSection.tsx`
- 스타일 및 테마: `apps/web/app/globals.css` 및 Tailwind CSS 유틸리티 활용.

### 🛠️ 개발 단계 (Step-by-Step 상세 로직)
1. **헤더 연동**: `apps/web/components/layout/` 내 공통 헤더 네비게이션 배치.
2. **캐치프레이즈 & 인트로 섹션**:
   - 감성 고딕 폰트(`font-1`~`font-5` 고딕 계열 또는 `Geist Sans` 결합)를 사용하여 정중앙 정렬.
   - 은은한 페이드인 애니메이션 효과 추가.
3. **예시 엽서 프리뷰 슬라이더**:
   - 3초 자동 슬라이드 전용 (클릭/호버 인터랙션 비활성화, cursor-default).
   - 예시 엽서의 3D 반사광 또는 그림자 효과 카드를 슬라이더 내에 렌더링.
4. **인라인 CTA 버튼**:
   - TTL 안내 문구 아래 본문 영역 내에 배치하여 푸터를 가리지 않고 자연스러운 스크롤 흐름 제공.
   - 호버 및 터치 시 부드럽게 크기가 커지는(scale) 마이크로 인터랙션 구현.
5. **카카오 애드핏 광고 배너 노출**:
   - CTA 버튼 하단에 `KakaoAdfit` 컴포넌트(`320x100` 배너)를 자연스럽게 페이드인 애니메이션과 함께 렌더링하여 수익화 공간 확보.

## 🚨 3. 철벽 코드 컨벤션 및 제약 조건
- **[300줄 분리 규칙]**: 랜딩 컴포넌트 및 서브 컴포넌트의 단일 파일 크기는 300줄을 절대 초과할 수 없음. 슬라이더나 애니메이션 유틸리티는 외부 파일로 즉시 격리.
- **[플랫폼 락]**: 오직 Web(Next.js App Router, React 19, TypeScript) 환경 전용 구현.
- **[하드코딩 금지]**: 엽서 프리뷰에 사용되는 예시 텍스트와 이미지 경로는 상수 파일(`constants/postcard.ts`)로 분리 정의.

## 🧪 4. 필수 테스트 케이스 및 검증 시나리오
- **[자가 진단 테스트 발굴]**: 모바일 화면에서 슬라이더 터치 드래그로 정상 전환되는지 검증.
- **[분기 및 예외 케이스 검증]**: 네트워크 지연으로 프리뷰 이미지 로딩 실패 시 Fallback UI(스켈레톤 카드)가 정상 작동하는지 확인.
- **[환경 및 반응형 검증]**:
  - iPhone SE 등 320px대 초소형 화면과 9:16 고정 비율 뷰포트에서 CTA 버튼이 화면 외부로 튕겨 나가지 않는지 검증.
  - 모바일 가로/세로 회전(Orientation) 시 화면 전체 깨짐 방어 확인.
- **[설명 주석 및 승인 강제]**: 모든 테스트 케이스 코드 상단에는 가독성 좋은 한 줄의 설명 주석을 명시하도록 설계하며 사전 승인을 거침.
