# Haroo Postcard Ad Gate Agent Reference

## 📝 1. 연동 기획 명세 (postcard-frontend.md)
- `/ad-gate/:id` (또는 `/postcard/ad-gate/:id`) 경로에서 동작하는 광고 노출형 브릿지 페이지.
- 소중한 감성 엽서 저장 및 공유 활성화 단계로 이동하기 전, 카카오 애드핏 광고를 정돈된 UI(카드 형태)로 보여주며 로딩 감성을 충전.
- 최소 3초의 딜레이 타이머를 작동시킨 뒤 하단 CTA 버튼 `[ 💌 엽서 보러가기 ]`을 활성화하여 자연스러운 스크립트 실행 환경 보장.

---

## 🤖 2. AI 개발 지침 및 설계 구조
### 🎯 목적
- 광고 영역의 이질감을 최소화하고 감성 카드 UI 프레임 내에 안전하게 정렬.
- 비동기 광고 스크립트 로딩 완료 시점과 관계없이 최소 3초 동안 사용자 몰입 유지를 위한 모션 그래픽/타이머 제공.

### 📦 패키지 및 타깃 클래스 경로 구조
- 라우팅 페이지: `apps/web/app/postcard/ad-gate/[id]/page.tsx`
- 컴포넌트 경로: `apps/web/components/postcard/ad-gate/AdGateContainer.tsx`

### 🛠️ 개발 단계 (Step-by-Step 상세 로직)
1. **스크립트 주입**: Next.js `next/script`를 사용하여 카카오 애드핏 외부 스크립트(`//pagead2.googlesyndication.com/...` 또는 카카오 애드핏 지정 SDK 주소) 비동기 로드.
2. **최소 딜레이 타이머 구현**:
   - `useState` 및 `useEffect`를 통해 3초 타이머(Countdown) 상태 관리.
   - 3초가 지나기 전에는 하단 CTA 버튼이 `disabled` 및 반투명 상태를 유지하며 로딩 애니메이션 노출.
3. **광고 영역 스타일링**:
   - 광고 컨테이너 박스 외곽에 부드러운 그림자(shadow-md) 및 테두리 둥글기(rounded-2xl), 배경 컬러 `#F9F6F0`를 씌워 메인 디자인 무드와 통일.
4. **활성화 및 이동**:
   - 타이머 완료 시 `disabled` 해제 및 클릭 이벤트 연결 -> `/share/${id}`로 안전하게 이동.

## 🚨 3. 철벽 코드 컨벤션 및 제약 조건
- **[300줄 분리 규칙]**: 광고 렌더링 로직과 타이머 애니메이션 컴포넌트는 단일 파일 기준 300줄 이하를 엄격히 준수.
- **[플랫폼 락]**: React/Next.js 웹 환경 전용 구현 가이드 고수.
- **[하드코딩 금지]**: 카카오 애드핏 클라이언트 키(Unit ID) 및 연동 설정값은 `.env`에서 `NEXT_PUBLIC_ADFIT_UNIT_ID` 형태로 바인딩하여 사용.

---

## 🧪 4. 필수 테스트 케이스 및 검증 시나리오
- **[자가 진단 테스트 발굴]**: 광고 스크립트 로드가 차단된 브라우저 환경(광고 블로커 등)에서도 3초 후 CTA 버튼이 정상 활성화되고 진행에 막힘이 없는지 에러 방어(Fallback) 검증.
- **[환경 및 반응형 검증]**:
  - 모바일 해상도(가로폭 360px 이하)에서 애드핏 배너의 고정 너비(예: 320x100 등)가 프레임을 벗어나거나 우측으로 삐져나가지 않는지 검증.
  - 가로 모드 진입 시 레이아웃 깨짐 현상 차단.
- **[설명 주석 및 승인 강제]**: 광고 초기화 및 리다이렉트 함수 상단에 구체적인 주석 명시 및 테스트 목록 사전 승인 처리.
