실행 명령: `cold_ig_lead_collection_convention.md 지침대로 진행해`

이 명령만으로 ig 탭 신규 수집·저장·재조회가 승인된다. dev 브랜치의 `lead_collection_convention.md`를 읽고 공통 기본 조건을 적용한다. 기본 목표 20건. 사용자 명시 변경이 없으면 추가 질문하지 않는다. 다른 탭은 중복 및 접촉 이력 검사 목적으로만 읽고 조사·저장하지 않는다. IG 미확인 후보를 이메일로 전환하지 않는다. 공통 문서의 실행 순서와 안전 기준을 적용한다.

- **A~F만 신규 행에 입력한다. G~I는 발송·접촉 기록이며 신규 리드 수집 단계에서 읽기만 한다. 기존 값과 공란을 절대 덮어쓰지 않는다.**
- A=단체/업종 유형, B=공식 단체명, C=국가·도시/지역, D=국내/해외, E=`@username`, F=`https://www.instagram.com/username/`.
- 공식 계정 확인 출처, 최근 12개월 활동 근거 URL 및 날짜, 서비스 적합성 판단, 수집일은 **신규 행의 F 셀 메모**에 기록한다. 메모 쓰기 불가 시 검증 로그 및 보고서로 근거를 보존하고 제약을 공개한다. 임의로 G~N을 자료 열로 사용하거나 새 헤더를 생성하지 않는다.
- 실행 직전 A1:I1을 실제로 읽어 매핑과 발송 기록 열을 확인한다. 구조 변경이 발견되면 기존 데이터 변경 없이 안전한 필드만 사용하거나 해당 채널 쓰기를 보류한다. 기존 `A~N` 가상 매핑을 사용하지 않는다.

## 후보 수집/검증
1. 국가·도시·업종·행사 키워드를 묶어서 공개 웹 검색. 공식 홈페이지의 IG 링크 및 공개 공식 프로필을 우선한다.
2. 이름만 비슷하거나 계정 검색 결과만 발견된 상태는 검증 완료가 아니다. 공식 사이트에서 해당 IG로 연결되거나 공개 계정이 공식 단체와 연결됨을 입증해야 한다. 팬·개인·비공개·사칭 계정은 제외.
3. 최근 12개월 안의 날짜 있는 공식 활동 1건 이상. 공식 웹사이트 활동만 확인되면 '단체의 활동 확인'이라고 기록하고 IG 포스팅을 직접 확인했다고 주장하지 않는다.
4. 하루상자 서비스 활용 근거를 공식 자료와 연결한다. 단순 활동 계정은 제외. 검색 색인일은 활동일로 취급하지 않는다.
5. 계정 URL은 프로필 URL로 정규화하고 /p/, /reel/ 링크를 쓰지 않는다.
6. `email` 및 시트의 다른 영업 탭과 기존 단체/도메인/계정/접촉 이력을 교차 검증하고, 같은 단체를 복수 채널에 신규 저장하지 않는다. 수신 거부/접촉 제외도 양쪽 적용.
7. 적합 후보를 배치로 묶는다. **동시에 여러 작업자가 IG 탭에 쓰지 않는다**. 단일 실행자가 마지막 데이터 행 확인 후 A~F 배치 입력, F 메모, 재조회 검증한다.

## 중단·완료
목표는 Google Sheets 신규 저장과 재조회 성공한 리드 수다. 첫 라운드 실패, 1~2건 저장을 이유로 멈추지 않는다. 지역·키워드·단체 유형을 바꾸어 다음 라운드 조사. 실제 도구 한도·접근 제한·검증 후보 고갈은 근거를 제시하고 부분 완료로 보고한다.
