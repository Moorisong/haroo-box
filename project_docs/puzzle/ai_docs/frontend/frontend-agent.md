# Puzzle Frontend Agent Reference

## 📝 1. 연동 기획 명세
- 하루퍼즐(Puzzle) 프론트엔드 라우팅 (`/puzzle` 하위 경로).
- Canvas API 및 직관적인 퍼즐 조각 드래그 앤 드롭 조작 화면 (가로/세로 반응형 듀얼 레이아웃).
- **다국어(i18n) 지원**: 한국어(KO) 및 영어(EN) 지원. 전역 `LanguageProvider` 및 `puzzle-i18n` 모듈을 통해 DB 사전 기반 번역 렌더링.

## 🤖 2. 목적 및 개발 지침
### 🎯 목적
- `puzzleStore`, `rankingStore` 상태 관리 연동 및 퍼즐 UI/게임플레이 화면 개발.
### 🛠️ 개발 지침
- 조각 맞춤 이벤트 최적화 및 렌더링 퍼포먼스 향상.
- **다국어 텍스트 처리**: 사용자에게 노출되는 모든 텍스트/알림/버튼 레이블은 하드코딩하지 않고, `usePuzzleTranslation` 훅 또는 `puzzle-i18n` 딕셔너리를 경유하여 렌더링.
- 가로 모드(`landscape`)와 세로 모드(`portrait`) 간 끊김 없는 플레이 상태 유지.

## 🚨 3. 제약 조건
- **[300줄 분리 규칙]:** 단일 파일 코드는 300줄 초과 금지. 초과 시 UI 서브 패널 분리.
- **[성능]:** 드래그 중 불필요한 리렌더링 방지 및 Canvas 렌더링 프레임 보장.
- **[하드코딩 금지]:** UI 문자열 직접 하드코딩 금지 (다국어 키 시스템 준수).
